最近事件

持久化配置

摄像头默认值

扫描注册时自动带入，单台摄像头仍可单独修改。

已保存摄像头

来源：data/config.json。这里显示历史保存记录，不代表摄像头当前一定在线。

摄像头注册

扫描网段或手动填写摄像头信息，注册后会保存到本地配置，并下发到本地采集器。

测试客流事件

本地采集器

3000 会自动启动和管理本地采集器；设备状态会显示 SDK worker 的连接结果。

连接配置

本机地址会由 3000 自动拉起；保存配置后会自动重新下发摄像头快照。

如果 3000 或 3100 端口被占用，Windows 包可以修改 config\ports.env 后重新启动。

控制台回调地址

采集器启动后会把心跳和客流事件回传到这些地址。

采集器状态

本地采集器由 3000 自动维护，并把心跳和事件回传给 3000。

hik 数据上报

采集器只回传到本地控制台；控制台再把客流和人体事件写入 hik 数据服务。

版本更新

配置版本更新 server / manifest URL，检查当前安装包是否需要升级。

已有安装建议在这里直接更新本机；下载安装包主要用于首次安装或人工兜底。关闭自动更新后，总部下发的更新仅提示、需在本页手动点击安装。
